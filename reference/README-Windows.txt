BADOING - WINDOWS DESKTOP PET

GET STARTED
1. Right-click the ZIP and choose Extract All.
2. Open BADOINGPet.exe from the extracted folder.

No installation is required. The artwork, animation, and sound are included.
The pet works offline.

CONTROLS
Click him: one badoing and one mouth animation.
Drag: move him. Drop near the taskbar to snap into place.
Right-click: mute, change size, sit on the taskbar, or quit.

Your count, position, size, and mute setting are saved in BADOING.settings
beside the app. Keep the extracted folder somewhere you can write files.
The pet does not add itself to Windows startup. Open BADOINGPet.exe to start
it again whenever you want.

Windows only. Built with Windows Forms and .NET Framework.
BadoingPet.cs is included as source code.

Character artwork and audio: Sassy the Sasquatch / The Big Lez Show.
Unofficial fan project.
